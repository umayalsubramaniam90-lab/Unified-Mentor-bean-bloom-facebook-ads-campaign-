# Facebook Ads Practice Campaign — Bean & Bloom Cafe

Unified Mentor Capstone Project (Digital Marketing Program)
**Prepared by:** S. Umayal
**Date:** April – September 2026

## Overview

This repository contains the project report for a practice Facebook Ads campaign built for **Bean & Bloom Cafe**, a fictional independent specialty coffee shop in Indiranagar, Bengaluru. The campaign was built and configured end-to-end in Meta Ads Manager as part of a capstone assignment to gain hands-on experience with campaign setup and optimization.

## What's in this repo

- `Bean_and_Bloom_Facebook_Ads_Report.pptx` — the full project report, covering:
  - Business overview and campaign objectives
  - Budget & bid strategy
  - Target audience and estimated reach
  - Ad format preference and placements
  - Ad creatives (Feed, Stories, Reels) and copy
  - Ad previews across placements
  - An observation on Meta's Advantage+ Creative (AI image generation)
  - Reflection, key learnings, and recommendations for a future live campaign

## Campaign Summary

| Detail | Value |
|---|---|
| Objective | Awareness |
| Daily budget | ₹200 |
| Duration | 30 days |
| Bid strategy | Highest volume |
| Target audience | Ages 18–45, 5 km radius around Indiranagar, Bengaluru |
| Placements | Facebook & Instagram Feed, Stories, Reels |
